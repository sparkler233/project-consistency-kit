## 目录结构

| 位置 | 内容 |
|------|------|
| `CLAUDE.md` | 项目背景、流程、协作规则与关键决策 |
| `README.md` | 项目地图（本文件） |
| `.claude/` | `/catchup`、`/同步` 命令与 hook 接线 |
| `一致性机制/` | 联动规则、机制说明、决策档案与收尾提醒 |
| 〔你的目录〕 | 〔正文、代码、素材或产物，请按项目补充〕 |

## 常用命令

| 命令 | 作用 |
|------|------|
| `/catchup` | 新会话开始时读取项目文档与 Git 状态，恢复当前工作上下文 |
| `/同步` | 收尾时检查文件联动，确认后写入、提交并推进 `synced` 标签 |
