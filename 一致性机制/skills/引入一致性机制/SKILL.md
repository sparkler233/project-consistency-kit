# 引入一致性机制(skill 封装)

本 skill 只是**语义触发层**。安装步骤的**唯一正本**在套件仓库(用指针不用拷贝,免双份漂移):

**`~/Developer/项目一致性机制/.claude/commands/引入一致性机制.md`**

## 执行方式

1. **完整读取**上述正本文件;
2. 严格按其中的步骤执行(步骤 0 探测现状 → 安装计划表 → 用户确认 → 增量合并安装,绝不覆盖项目已有文件);
3. 正本读不到(套件迁移 / 改名)→ 停下问用户套件在哪;找到后建议按套件《初始化新项目.md》「套件首次落机」一节重建本 skill 的符号链接。

## 等价物

斜杠命令 **`/引入一致性机制`**(全局,驻留 `~/.claude/commands/` 符号链接)与本 skill 指向**同一正本**,只是触发方式不同:命令靠显式输入,本 skill 靠语义自动命中。

## 绿地情形

全新空项目同样适用(正本就是「所有目标文件都不存在」的退化情形设计);也可以整包 rsync 套用,见套件《初始化新项目.md》。
