# 关键决策档案

> 本文件是 `PROJECT.md`“关键决策记录”的**历史档案**。PROJECT 由 `/catchup` 在会话开局按需读取,
> 决策记录只保留**最近 ~10 条**(工作集);更早的条目由 `/同步` 按联动目录**规则 6** 轮转到这里。
> 类比 git:PROJECT 的决策节 = 工作集,本文件 = 历史。设计动机见 `机制设计说明.md` 决策 11。
>
> - **怎么进来**:`/同步` 发现决策记录超限(>10 条)→ 提议轮转 → 用户确认 → 最老的条目**剪切**到本文件末尾(保持时间升序、原行原样,不改写)。
> - **怎么使用**:按需查阅 / grep。本文件**不进 Part A 中枢清单**,`/catchup` 不默认读取——历史不交「每轮 token 租金」。
> - **轮转不影响任何现行约定**:决策的操作性内容在拍板时就该改写进 PROJECT 正文或对应领域文档,记录行只是审计线索。
